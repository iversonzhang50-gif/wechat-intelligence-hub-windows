# Contributing

Bug reports, compatibility results and documentation feedback are welcome. Reproduce problems with the bundled fictional samples whenever possible, and follow `SECURITY.md` before sharing logs or screenshots.

During the Preview stage, open an Issue before submitting a substantial code change. The project is keeping copyright ownership clear so it can remain AGPL open source while also offering separate commercial licenses. Unsolicited substantial code contributions may not be merged until a contributor agreement is available.

Small documentation corrections may be submitted as pull requests under `AGPL-3.0-only`. Do not submit code, data or documentation copied from WeChat, Tencent, an unpublished third-party CLI, a proprietary repository, or any source you do not have the right to contribute.

Never include real chat messages, contact data, WeChat IDs, chatroom IDs, databases, access material, local profiles, client information, credentials, tokens or private filesystem paths.
