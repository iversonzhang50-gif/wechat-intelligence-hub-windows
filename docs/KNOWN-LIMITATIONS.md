# 已知限制

- 真实账号读取只在一台Windows电脑、微信4.1.13.12完成历史实读验证；新打包入口另做虚构数据验证，不声称在所有Windows或微信版本通过。
- 只有本机已经保存的数据可读；手机未同步内容、已删除或过期附件不保证可恢复。
- 图片独立解密、语音转写、附件自动保存、完整媒体读取没有完成本Windows版验收。旧能力列表中的media=true不等于文件已取得。
- 历史验证中3个辅助全文索引库quick_check返回SQL logic error，原因仍未完全确认；未修改这些原库。已验证正文查询不依赖它们。
- 日报机器初筛需语义编辑；金额、身份、截止时间、已成交和已履约必须以证据及人工确认为准。
- Profile初始重点由用户提供；索引仅覆盖已经导入的消息，实时Reader范围和索引范围不同。
- 不内置后台扫描、定时提醒、自动回复或微信写操作。
- Python3.12 x64与锁定Windows wheel为本版安装目标；ARM64、32位、其他Python主次版本、无网络且无离线依赖目录的安装尚不支持。
- 安装前需系统已有Python3.12；不提供EXE或内置Python。运行时移动目录需重新验证，注册技能的本地映射不能随源码发布。
- 原有上游macOS测试和访问脚本作为源码保留，但不是Windows支持承诺。Windows验收由windows/self_test.py提供。
