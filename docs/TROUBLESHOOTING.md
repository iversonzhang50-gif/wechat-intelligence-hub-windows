# Windows故障排查

| 现象 | 处理方式 |
|---|---|
| 找不到Python或wheel不兼容 | 核对Python3.12 x64；Install.ps1支持-PythonExe指定解释器。不要更换成未验证的依赖组合 |
| 下载停滞 | 安装限制重试和超时；使用同一锁文件对应的已核验wheel目录，Install.ps1支持-Wheelhouse。不要关闭TLS校验或使用不明镜像 |
| 已有.runtime或同名Skill | 安装保留原件，不覆盖。新解压目录验证后再决定迁移；不自动删除旧环境 |
| 私有配置“拒绝访问” | 检查执行账号与本机系统授权；不公开密钥、不放宽到所有用户；不是重新获取key的理由 |
| doctor缺配置／缺key | 按WINDOWS-ACCESS.md先复用已有文件，再区分缺失与不可读。需要获取时另行说明和确认 |
| 微信升级后失败 | 停止重复查询，核对版本、配置路径和只读诊断。不能从旧版本成功推出新版本兼容 |
| 明明有聊天但查不到 | 确认时间窗口、本机同步情况、关键词、联系人身份及查询使用的是实时Reader还是旧索引 |
| 图片只有占位符、文件只有文件名 | 媒体未完整验收；不把路径或文件名作为正文内容 |
| HTML缺少Pandoc | 在隔离环境核对pypandoc-binary固定依赖；渲染器会自动找其Pandoc，不要求修改系统PATH |
| Windows下调用.sh失败 | 使用wechat.cmd或Skill中的.ps1入口；不要尝试通过改变系统策略强行运行macOS流程 |

记录错误阶段、版本和错误码即可。提交Issue前去除真实路径、账号标识、聊天、联系人、密钥以及包含这些内容的截图。
