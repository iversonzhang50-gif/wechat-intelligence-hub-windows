# Release roadmap

## 首发 — WeChat Intelligence Hub

首发叙事只讲一件事：如何把高噪音微信聊天变成可核查、可执行的个人情报。

发布内容：

- `wechat-cli`
- `wechat-intelligence-hub` Skill
- `wechat-intelligence-hub` local engine
- 虚构 Demo、隐私边界、完整验证脚本和 Preview 限制

## 下一阶段 — X Content OS

主叙事：从素材、爆款机制和个人经验，到可发布的单贴、Thread、X Article，再到排版与复盘。

公开前必须完成：

- 把维护者专属名称、绝对路径、时区和私有 Growth OS 依赖改成 Profile / 环境配置。
- 保留一个可选的 `rion` 示例 Profile，但默认运行不依赖它。
- 使用虚构书签、历史推文和表现数据完成一次干净环境演示。
- 将 `x-article-layout` 和 `x-video-upload` 作为同一内容系统的适配器，而不是三个互相竞争的产品。

## 后续

- 本仓库只维护微信个人情报库、`wechat-cli` Skill 和 Rion WeChat Reader。
- `rionwu-skills` 作为品牌合集收录本项目的介绍、状态和安装链接，不复制 Reader 源码或提交历史。
- X、开票、数字人、记忆系统和商业 OS 在各自完成公开化检查后，通过合集进入对应仓库。

## Release rule

同一天最多讲一个旗舰故事。每次发布都保留独立的文章、主贴、演示和版本标签；合集 README 负责承接长期品牌与交叉发现。
