# Windows发布候选验证

## 验证分层

1. **已有安装的真实账号验证（历史结果）**：Windows微信4.1.13.12，Reader连接、私聊、群聊、公众号、成员、标签及关键词查询实际通过。本包只保留这些功能结论，不携带账号、联系人、记录数量或原始验证日志。
2. **本次候选的虚构数据验收**：新建隔离环境；测试数据库、消息、密钥和联系人均为虚构。不通过真实账号“空跑”获取新的访问材料。
3. **独立路径安装**：包含中文和空格的新解压目录，创建新虚拟环境；从固定官方URL取得七个依赖wheel并校验SHA256，再本地安装。没有复用本机旧微信安装目录。
