# Security

- Reader 只允许打开用户明确配置的本地数据库路径。
- 所有数据库查询通过临时快照进行，不修改微信原数据库。
- 密钥必须保存在仓库之外，并使用仅当前用户可读的文件权限。
- 错误、状态和测试输出不得显示密钥、联系人或聊天正文。
- macOS 通知模式必须始终标为 `incoming_preview_only`。
- 不接受包含真实数据库、密钥、内存转储或聊天导出的公开 Issue。
- `rion-wechat-access` 是独立的实验性接入助手，不是只读 Reader。它可在用户确认具体外部工具及重启/调试/重签名副本的影响后，通过 macOS 系统授权调用该工具；本助手不读取、接收或保存管理员密码。外部工具是否跳过密码持久化必须逐版本审核，不能由哈希匹配或确认参数替代。
- 接入助手不覆盖已有 Reader 配置。失败保留人工恢复锁，不自动重试；超时后 GUI 副本或授权子进程可能仍需人工检查。密钥导入先在私有临时代际目录验证，再原子发布新配置。
